\textbf{Intended use}\\[-0.2em]
\begin{itemize}
  \item Triage likely brick kiln locations from satellite crops.
  \item Review map markers, confidence, tile evidence, and OBB overlays.
  \item Support environmental monitoring. It is not a standalone enforcement system.
\end{itemize}

\textbf{Known limitations}\\[-0.2em]
\begin{itemize}
  \item Saved outputs include overall validation metrics, not final Bangladesh-only metrics.
  \item Demo tile coverage is limited to five districts and ten seeded tiles per district.
  \item Upload predictions without georeferenced tiles have approximate coordinates.
  \item Class imbalance is substantial; FCBK dominates the train labels.
  \item Visual false positives can occur for industrial roofs, roads, fields, and kiln-like shapes.
\end{itemize}

\textbf{Ethical and deployment concerns}\\[-0.2em]
\begin{itemize}
  \item Human review is required before enforcement, public accusation, or site-level publication.
  \item Satellite imagery and model outputs can be outdated; field validation should confirm sensitive findings.
  \item Thresholds should match the review context: high recall for screening, higher precision for action.
  \item Dataset and pretrained model licenses must be checked before external release or commercial reuse.
\end{itemize}
